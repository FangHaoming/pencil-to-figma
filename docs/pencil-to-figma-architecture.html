figma to pen 插件架构

Figma 插件：聚焦从 Figma 导出 `.pen`；下图展示当前单页导出流程的主链路

通信与隔离

  • • UI 与 Main 仅通过 postMessage 交换消息（见 Figma Plugin UI 文档）
  • • manifest 中 networkAccess 为 none：插件逻辑不依赖外网
  • • documentAccess: dynamic-page，随当前文档操作节点

导出 `.pen`

  • • 导出 .pen：选中节点 → UI 发起导出 → Main 用 figma API 读树与样式 → ImageExporter（exportAsync 等）→ PenSerializer → postMessage 将 JSON 与资源交给 UI → downloadExportPackage 触发浏览器下载
  • • 当前产品目标：聚焦导出链路，结构优先于纯视觉

工程结构

  • • Main：TypeScript 编译为 dist/code.js
  • • UI：Svelte + Vite → dist/ui.html
  • • 共享：src/shared 中的类型与消息协议（pen-types、message-types）
